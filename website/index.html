01 // INGESTION

Specs become binding code, not loose suggestions.

ratchet sync reads your markdown requirements and invokes Kane CLI’s assurance engine (context ingest → design tests → maintain reconcile). It generates concrete test scenarios under .testmuai/tests/ covering 100% of defined criteria.

02 // VERIFICATION

Live headless Chrome execution via non-TTY NDJSON stream.

runner.ts spawns kane-cli testrun run --agent with an ignored stdin stream to avoid interactive prompt deadlocks. It intercepts line-by-line NDJSON events, capturing step-level status, memory mutations, and DOM assertion verdicts in real-time.

1// src/engine/runner.ts
2const child = spawn("kane-cli", ["testrun", "run", "--agent"], {
3 stdio: ["ignore", "pipe", "pipe"] // Prevents interactive TUI hang
4});
5
6readline.createInterface({ input: child.stdout }).on("line", (line) => {
7 const event = JSON.parse(line);
8 if (event.type === "step_failed") emitFailure(event);
9});
03 // DIAGNOSIS

Token-efficient Repair Packets instead of 5,000-line log dumps.

When a step fails, packet.ts isolates the exact broken assertion, root-cause hypothesis, extracted vs. expected visual state, and local .evidence session replay command. The AI coding agent receives precise coordinates to patch code without getting distracted.

1{
2 "locked": false,
3 "verdict": "RATCHET_BLOCKED",
4 "failingStep": "Apply SAVE20 promo code",
5 "rootCause": "Assertion mismatch: expected '$80' but was '$100'",
6 "memoryDiff": { "expected": "$80", "actual": "$100" },
7 "evidenceReplay": "kane-cli evidence serve .testmuai/runs/latest.evidence"
8}
04 // HARD GATE

The codebase cannot advance until Chrome confirms green.

ratchet hook installs an immutable .git/hooks/pre-push guard. If any requirement fails verification, the ratchet stays blocked and Git aborts the push with exit 1. Once all scenarios pass, the gate snaps to locked: true and allows the branch forward.

1# .git/hooks/pre-push
2#!/usr/bin/env bash
3ratchet verify --no-report || {
4 echo "[ratchet] ✖ PUSH REJECTED: Acceptance criteria unverified."
5 exit 1
6}
7echo "[ratchet] ✔ RATCHET LOCKED. Push approved."

Command Reference & Schema

Every interface into the Ratchet verification state machine.

Command Description Exit Code
ratchet sync --prd <file> Parses PRD markdown, extracts acceptance criteria, and generates TestMu AI Kane test scenarios. 0 on success, 1 on malformed spec
ratchet verify Runs Kane CLI against live app URL, evaluates assertions, streams NDJSON, and checks ratchet lock. 0 if verified, 1 if criteria fail
ratchet verify --json Outputs machine-readable RepairPacket JSON payload directly to stdout for agent consumption. 0 if verified, 1 if criteria fail
ratchet hook --install Installs pre-push Git hook enforcing verification before commits reach origin. 0 on install
